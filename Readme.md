## 📖 About The Project

Rock Paper Scissors is a fun and interactive browser-based game built using **HTML**, **CSS**, and **Vanilla JavaScript**. Players compete against the computer, which randomly selects a move. The game keeps track of wins, losses, and ties using **Local Storage**, ensuring scores remain even after refreshing the page.

### 🎯 Key Highlights

- 🎮 Interactive Rock, Paper, Scissors gameplay
- 🤖 Random computer move generation
- 💾 LocalStorage support for saving scores
- 📊 Live score tracking
- ⚡ Auto Play mode
- ⌨️ Keyboard shortcuts
- 📱 Responsive user interface

## 🎮 How to Play

1. Click **Rock**, **Paper**, or **Scissors**.
2. The computer randomly selects its move.
3. The result is displayed instantly.
4. Your score is automatically updated.
5. Click **Reset Score** to clear the saved score.
6. Click **Auto Play** to let the game play automatically.

## 🎯 Game Logic

- Paper defeats Rock
- Same move results in a Tie
