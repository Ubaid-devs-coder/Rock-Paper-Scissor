# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. The game allows players to compete against the computer, tracks scores using Local Storage, and includes an Auto Play mode.

---

## 🚀 Features

- ✊ Play Rock, Paper, or Scissors against the computer
- 🤖 Random computer move generation
- 📊 Live score tracking
- 💾 Score saved using Local Storage
- 🔄 Reset score functionality
- ⚡ Auto Play mode
- ⌨️ Keyboard shortcuts
- 📱 Responsive and simple UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 How to Play

1. Click **Rock**, **Paper**, or **Scissors**.
2. The computer randomly chooses its move.
3. The result (Win, Lose, or Tie) is displayed.
4. Your score updates automatically.
5. Click **Reset Score** to clear saved scores.
6. Click **Auto Play** to let the game play automatically.
